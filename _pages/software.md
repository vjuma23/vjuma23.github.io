I use scientific computing extensively in research and teaching, particularly for the numerical solution of ordinary and partial differential equations and for finite-element simulation.

## Main tools

- **FEniCS / FEniCSx** — finite-element modelling for PDEs and mechanochemical systems
- **PETSc** — scalable linear and nonlinear solvers
- **MATLAB** — ODE/PDE simulation, parameter estimation, bifurcation and numerical analysis
- **Python** — numerical computing, data processing and scientific workflows
- **Gmsh, meshio, PyVista and ParaView** — meshing and visualization

## GitHub projects

- [FEniCS tutorial](https://github.com/vjuma23/fenics-tutorial) — teaching and tutorial material for finite-element methods with FEniCS/FEniCSx.
- [Oscillatory dynamics](https://github.com/vjuma23/Oscillatory-dynamics) — computational work related to oscillatory reaction–diffusion dynamics.
- [Diffusion-driven instability in a 3-component RDS](https://github.com/vjuma23/Diffusion-driven-instability-in-a-3-component-RDS) — code related to diffusion-driven instability in reaction–diffusion systems.
